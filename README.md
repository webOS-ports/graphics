# webOS-Ports graphics sources

Source art (Photoshop `.psd` files) from the **WebOS-Ports wiki**, originally
attached to the [`Graphics_Work`](https://webosports.miraheze.org/wiki/Graphics_Work)
page of the self-hosted wiki at `webos-ports.org` (offline since 2025).

These files could not be carried over when the wiki moved to Miraheze in 2026:
Miraheze does not permit `.psd` or `.zip` uploads. Every other asset
(png / jpg / gif / svg) migrated successfully. They are preserved here so the
source art stays available and versioned.

- **122 files**, 169.3 MB total
- `Graphics_Work.wikitext.txt` — the original wiki page text, kept for reference
  so the descriptions and groupings of these assets are not lost.

## Background

Open webOS shipped its UI graphics as 72dpi PNG-24 assets, and the sources for
those were never open sourced. This collection is the community's redrawn
higher-density source art, created so the UI could be scaled to devices with
greater pixel densities.
